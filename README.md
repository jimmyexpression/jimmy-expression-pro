# Jimmy Expression Pro

Sistema de gestión completo para salón de belleza.

## Stack
- **Frontend:** Next.js 14 + React 18
- **Base de datos:** Supabase (PostgreSQL)
- **Deploy:** Vercel

## Módulos
- Dashboard, Agenda, Clientes, Caja, Apertura/Cierre
- Finanzas, Nómina, Inventario, Servicios
- Estadísticas, Marketing, Marketplace
- Citas Online, Usuarios & Roles, Configuración

## Deploy
1. Fork este repositorio
2. Conectar con Vercel
3. Deploy automático

## Variables de entorno
No se requieren — Supabase está configurado directamente.
